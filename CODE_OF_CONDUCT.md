# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, discussions and any other project space.

## Reporting

The project has no dedicated conduct email address. To report unacceptable behavior, use either route:

1. **Contact request (recommended).** Open an issue with the "Code of conduct contact request" form (label `conduct`). It is public, so put no details in it: the maintainer replies there with a private way to talk and then closes the issue.
2. **Fully private.** If even a public contact request is not safe for you, use GitHub's private reporting form (https://github.com/talalkashar/agent-security-audit/security/advisories/new) and start the title with "Conduct:". That form is meant for vulnerabilities; this project also accepts conduct reports there because it is the only private channel GitHub offers. The maintainer will move the conversation out of the advisory and close the draft advisory afterwards.

Reports are read by the maintainer only and kept private. If the report is about the maintainer, say so in the contact request; there is no second maintainer, so you may prefer to report to GitHub directly (https://support.github.com/contact/report-abuse).

## Enforcement

The maintainer may remove, edit or reject comments, commits, issues and other contributions that break this code, and may block a contributor temporarily or permanently, following the enforcement guidelines in the Contributor Covenant.
